## Less is More

Use existing libraries, standards, and runtimes to their full potential. Add only a thin layer when it helps.

Gn8 software lets you keep the schemas, frameworks, and validation tools you have chosen.

Running everywhere should not compromise performance or the strengths of each environment. We build software that works naturally and efficiently on each platform.

## The best, right from the start

Choosing takes time. You compare options, test them, and may still regret the choice. While you decide, you are not building.

Gn8 aims for the best. We build software that ends the comparison, strips away the unnecessary, and makes the core excellent. The less we add, the more naturally it fits across environments and the longer it lasts.

Pick something to get started and find it is the best choice. We want to create more experiences like that.

# Gn8

## Less is More

We develop and maintain open-source development platforms, libraries, and CLIs. We use existing standards and runtimes, adding only what is needed.

Our products and managed services build on that OSS. We also help with adoption and maintenance when needed.

## とりあえずが最高峰

最小限のもので、最大限の効果を。標準・ランタイム・既存の資産を活かし、必要な薄い層だけを足します。

開発基盤・ライブラリ・CLI をつくり、公開後も改善と保守を続けます。その OSS を土台に、プロダクト・運用サービスを提供します。
